# ResumeTailor

ResumeTailor is a personal project designed to help software engineers create highly targeted resumes for specific job postings.

Instead of relying on AI to generate or rewrite resume content, ResumeTailor uses a curated library of resume bullets written and maintained by the user. AI analyzes a job description, identifies the skills and technologies being requested, and intelligently selects and orders the most relevant bullets for that specific opportunity.

The goal is to reduce the time spent tailoring resumes while ensuring every bullet remains accurate, authentic, and representative of the candidate's real experience.

## Planned Features

- Build and manage a curated library of resume bullets
- Analyze job descriptions from supported job boards
- AI-powered job requirement extraction
- Intelligent ranking and ordering of existing resume bullets
- Generate tailored PDF resumes
- Track job applications
- Store resume history and previous analyses
- Chrome Extension for one-click job analysis
- Web dashboard for managing resumes and applications
